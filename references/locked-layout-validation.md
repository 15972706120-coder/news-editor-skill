# 锁定版式与分区验收（资讯快讯）

> **当前激活合同**：本文件是 [layout-lock-v3.json](../assets/references/locked-layout/layout-lock-v3.json) 的人读镜像，与 [当前制作配置](current-production-profile-v3.md) 共同构成现行版式规范。V1、V2 锁定文件只供回看旧成片。

本版式由账号四条高播放成片逐帧实测得到（720×1280@25fps 平台转码件，按 1.5 倍归一）。制作封面、正文或最终验收时必须读取；用户没有明确要求改版时，不得凭感觉改变这里的坐标、字号、颜色层级或板块顺序。参考图中的新闻事实、人物和画面不能复制到其他选题，只复用版式关系。

## 1. 唯一坐标源

机器可读参数以 [layout-lock-v3.json](../assets/references/locked-layout/layout-lock-v3.json) 为唯一坐标源。本文件出现的坐标只用于解释；发生差异时以 JSON 为准并修正文档。除 config.json、本文件和锁定 JSON 外，其他文档不复述坐标。

实拍带等区域的纵向位置不是固定值，而是由当前文案“堆叠”出来的：标题块行数 → 结果行（可选）→ 免责小字（可选）→ 实拍带。`production_contract.body_geometry` 与渲染器、分板脚本使用同一计算。

## 2. 参考资产

版式参考图位于 `assets/references/v3-reference/`（参考接触表、字幕滑入逐帧图、字体细节图），由 `scripts/build_layout_reference.py` 用合成素材和示例文案渲染，不含账号或第三方画面；对标成片的原件不随仓库分发。封面资产沿用 `assets/references/` 下的既有文件。V2 分页版式的参考帧归档在 `assets/references/locked-layout/legacy-v2/`，仅回看旧成片时使用。

## 3. 静态预览与编码后分板验收

先检查静态封面与字幕块预览，再渲染一次草稿并运行分板验收；不要求未生成的 MP4 先抽帧。坐标使用 XYWH；封面 `*_visible_bbox` 是参考文字的 XYXY 样本边界，不是所有新字符串的固定宽度。保持锁定字号上下限与参考视觉中心，按真实字形测量居中。

```powershell
python scripts/extract_layout_proof.py <草稿或最终MP4> --timeline <timeline.json> --qa-report <qa.json> --render-report <render-report.json> --out-dir <工作区/qa/layout-proof>
```

脚本抽取封面、第 1 帧、每个字幕块到达后的稳定帧、每个镜头切点前后帧和末帧，并把每个稳定帧拆成 `header`（标题区）、`footage` 或 `panel`（实拍区/面板）、`caption`（字幕区）三个独立文件，同时导出封面 3:4 图与 270×360 缩略图。脚本只证明尺寸、帧数和证据文件完整；以下视觉项必须实际逐张打开检查。

### A. 封面板

- 看 `cover.png`、`cover-3x4.png`、`cover-thumbnail-270x360.png`。
- 画面区内是单独检索的高清图片或原片清晰关键帧，主体在 270×360 中仍可辨；无源文字、水印、模糊、马赛克。
- 叠加前另看无标题 3:4 底图、无标题缩略图与候选接触表；四项人工评分分别达到 config 门槛。
- 只有 V3 透明四角框；青色主标题、白色副标题各一行，字号在上下限之间；不得出现主播、纯黑空底或素材说明。

### B. 标题区（header）

- 标题块行数、样式顺序与文案一致，末行为黄色斜体；每行在锁定宽度内，无横向压缩。
- 结果行为红字白边、单独一行；有资料画面时左上有免责小字。
- 来源小字只出现在右下角来源安全框；标题块与结果行不出现任何媒体名。

### C. 实拍区（footage）或面板（panel）

- 视频形态：四边由有效素材填满，无黑边、空白或手工补边；主体未被裁切关键部位。
- 顶部/中部源标题、日期条为零；底部字幕要么已移除，要么局部强模糊后完全不可辨认；仅当事方原话片段允许保留源字幕。
- 纯图文形态：面板位置与透明度符合锁定值，正文不越出面板底边。

### D. 字幕区（caption）

- 字幕块为黄色黑边斜体，居中于锁定中心，行数不超过上限，最长行不超过锁定宽度。
- 文字无错字、无叠影；背景为素材模糊副本而不是纯色或黑块。
- 来源小字在安全框内、灰色、不抢眼。

### E. 到达帧、切点与末帧

- 每个字幕块的滑入过程帧有拖尾、无闪烁，到位帧文字完整清晰；旧块在新块到位时已滑出画面。
- `cut-XX-before.png` 与 `cut-XX-after.png` 直接切换，无叠化、重影、黑帧。
- `final-frame.png` 保持最后一个字幕块与完整实拍带，不提前清空。

## 4. 强制失败条件

任一分板缺失、尺寸不符、未实际查看，或出现下列情况，状态固定为 `BLOCKED_VISUAL`：

- 封面无可识别真实画面、出现源文字或只剩标题与空底；
- 无标题缩略图看不清内容、与事实包仅宽泛相关，或四项人工评分任一未达 config 门槛；
- 标题块、实拍区、字幕区边界与锁定计算结果不一致超过 2px；
- 实拍带有黑边、空白或手工模糊补边；
- 标题块末行不是黄色斜体，或来源媒体名进入标题块/结果行；
- 资料画面缺少免责小字，或字幕与标题把资料画面、评论截图当成事实来源；
- 字幕块在到位前出现、滑入半途停住或新旧块叠影；
- 只查看完整帧，没有查看脚本拆出的区块；
- 使用参考图的示例新闻文字代替当前新闻文案。

完成分板验收后才能发布；最终编码 MP4 必须有自己的验收证据，同一文件哈希可复用，不为标注“最终”重复编码。
