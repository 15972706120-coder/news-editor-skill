# 固定视觉、分页与声音模板

> **当前覆盖规则**：新制作必须先执行 [当前制作配置 V2](current-production-profile-v2.md)。下文 V1 坐标、Edge TTS 和封面局部模糊内容仅为历史说明，不得覆盖 V2。

本模板用于用户没有另行指定视觉或声音方案的新闻短视频。制作封面、正文页面、分页配音、混音或最终视觉验收前读取本文件，并按需检查对应参考资产。用户当次明确要求优先于本模板；参考资产中的示例新闻文字、人物和画面只用于观察样式，不得复制到其他新闻成片中。

## 分页、字数与时间轴

“内容简介”是分页正文的事实文本，不包含顶部主标题、副标题、栏目角标、页码和来源行。封面另有独立短文案，不复用完整报道标题。

1. 默认成片固定为 14.000 秒、30fps、420 帧。封面仅占第 0 帧，正文从第 1 帧到第 419 帧，共 419 帧。
2. 默认 2 页。标准内容简介建议为 40–84 个全角字宽，每页通常 20–42 个全角字宽、最多 3 行；按语义分页，不拆开人名、机构名、日期、数字单位、否定词或因果关系。
3. 汉字和全角符号计 1 个全角字宽；ASCII 字母和数字按实际排版测量，不用简单字符数替代宽度。正文最终以 744px 安全宽度和固定 48px 字号实测换行为准。
4. 不再采用固定 4 秒/页，也不按字符数机械增加页面。先分别生成自然语速配音，测量每段真实时长，再为每页预留约 0.15 秒开头和至少 0.25 秒尾音，以语义切点分配页帧。
5. 每页最少需要 `ceil((voice_duration + 0.40) × fps)` 帧。两页所需帧数总和不得超过 419；有余量时优先均衡阅读停留和切页节奏，不靠拉长静音隐藏文案过短。
6. 标准双页通常各占约 6–8 秒，具体帧数写入 `edit-plan.md` 和验证命令，例如 `210,209`。切点必须落在句末或自然停顿，不能截断尾字。
7. 固定 14 秒内装不下时，先压缩口播、删除重复背景和调整双页语义；禁止明显加速配音或把字号缩小。只有用户允许延长，或关键信息确实不能删时才增加第 3 页，并同步明确新的总时长和逐页帧数。默认扩展档为 18 秒、540 帧。
8. 用户明确指定总时长时，`expected_frames = round(duration × fps)`；封面帧包含在总帧数内。所有页面帧数之和必须等于 `expected_frames - cover_frames`。
9. `edit-plan.md` 必须在渲染前写明：每页口播原文与实测秒数、页帧数、每个使用片段的源文件与入/出点、该段支持的正文、目标裁切与字幕处理、封面候选帧。页面 1 优先交代“发生什么/谁”，页面 2 交代“回应、规则、影响或处理进展”；切点落在完整句或自然停顿，不能只按画面时长均分。
10. 单段画面通常保留 1.5–4 秒；稳定的关键现场可更长。避免同一静止画面长时间停留，也不为了“镜头多”塞入快速闪切、源素材叠化或模糊过渡帧。素材不足时优先在已下载的 1–3 条源视频内补充互补时段。

## 固定字体与颜色

全片使用微软雅黑。粗体层级在运行时用 `Join-Path $env:WINDIR 'Fonts\msyhbd.ttc'` 定位，常规层级用 `Join-Path $env:WINDIR 'Fonts\msyh.ttc'` 定位；渲染前确认字体存在。不得写死系统盘符，也不得静默替换成外观差异明显的字体。

固定色值：

- 封面青色：`#0AEAE6`。
- 标题黄色与强调条：`#FFDE00`。
- 正文红色强调：`#FF1837`，配白色细描边。
- 主文字：`#FFFFFF`。
- 来源文字：`#717171`。
- 页面底板：深海蓝纵向渐变 `#071529 → #0B2D55`，可叠加不超过 2% 的细颗粒；禁止使用大面积纯黑 `#000000`。

## 封面版式（1080×1920）

详细执行 [cover-platform-layout-v2.md](cover-platform-layout-v2.md)，以下为硬性摘要：

- 画面区固定为锁定 JSON `cover.background_video` 的区域，使用清理后的下载素材按 `cover` 等比例铺满。
- 直接叠加透明的 `cover-frame-lines-v3.png`；`cover-frame-overlay-v2.png` 只用于位置比对，不得作为不透明整图覆盖真实底图。
- 封面主标题为 144px 青色粗体，4–7 个全角字宽、硬上限 8；副标题为 112px 白色粗体，5–10 个全角字宽、硬上限 12；均保持单行。超过宽度时改写文案，禁止缩字。
- 文字可见区域参考：主标题 `y=1140–1250`，副标题 `y=1309–1405`；位置和颜色以 V2 文字参考为准。
- 底图必须是事件直接相关、无源文字、非主播、非演播室和非第三方概念渲染的真实下载素材。
- 封面真实画面区内必须始终能看见并辨认真实下载画面（区域坐标见锁定 JSON 的 `cover.background_video`）；禁止用深色参考资产、纯黑色块或接近纯黑的均匀区域盖住主体。缩略图尺寸见 config.json 的 `cover` 段，其中应先识别到事件/场景主体，再读到标题。
- 清理底图时先调整裁切与焦点；只有仍残留的原文字区域才允许精确局部模糊。不得把顶部、右侧或底部的大块有效信息整体模糊；模糊后主体在 270×360 缩略图中仍须一眼可辨。
- 封面不得出现“资料画面”“素材：抖音@xxx”或其他素材说明。
- 渲染前必须检查中央 3:4 裁切后的 270×360 双列缩略图；文字小、标题过长、截字或主体不清均直接失败。

## 正文页版式（1080×1920）

默认使用用户确认的深海蓝三段式版面，不使用浮动大卡片、纯黑底板或整幅模糊背景：

- 顶部标题区、副标题条与黄色分隔线：结构与坐标见锁定 JSON 的 `body_page.header/subtitle_bar/divider`（字号同字段），底色为深海蓝渐变（色值见锁定 JSON `colors` 段）。
- 顶部标题底板和正文底板统一使用深海蓝渐变；黄色副标题条与分隔线保持不变。不得把纯黑或接近纯黑的大色块作为视频底板。
- 实拍层：区域为锁定 JSON 的 `body_page.footage`。只使用下载素材，按 `cover` 等比例放大并移动焦点，四边必须由有效画面填满；不得用模糊复制背景、黑边或空白补足。
- 正文区：全宽深海蓝底板，区域为锁定 JSON 的 `body_page.copy_board`；角标、页码、白色正文、红色重点、来源与底部黄线的安全框全部以同一 JSON 为准，文档不复述数值。
- 红色强调行允许与平台左侧蓝色账号 Logo 轻微叠层，但叠层预览后至少 75% 的红字面积和完整语义仍须可读；白色说明行不得被账号栏遮挡。
- 顶部黄线必须贴近副标题条；实拍和底部文字包装整体向上衔接，不能留出大块无意义黑区。

所有字号和位置均为固定默认值。只有用户明确要求其他风格或提供新的平台遮挡截图时才允许调整；调整必须记录像素参数并重新做平台预览。

## 固定音色与混音

- 默认配音为 MiniMax T2A（见 [MiniMax TTS 集成](minimax-tts.md)）：模型、默认音色与全部初始参数以 `config.json` 的 `voice` 段为唯一事实源。调用 `scripts/minimax_tts.py` 时核对返回 JSON 的 `voice_source`，防止静默回退；同一项目所有页面和后续版本保持同一提供方、voice ID 与基础参数，并写入项目清单。用户明确指定其他声音或提供配音时，以用户要求为准。
- 音色要求为清晰、可信、克制、重音准确，不使用夸张情绪、广告腔或角色化表演。无法在自然语速内放入页面时，先精简口播或增加页面；只允许轻度调整 `speed`，且整个项目保持一致。默认 voice 不可用时停止默认配音节点，列出可用普通话女声候选并取得用户选择，不静默换声，也不宣称与参考样片是同一声纹。
- 分页分别生成语音并测量真实时长，再按本文件的动态页帧方案对齐；每页保留约 0.15 秒入场和至少 0.25 秒尾音，不得截断尾字。
- 响度与真峰值目标、逐页人声/BGM 避让差等全部数值见 `config.json` 的 `mix` 段；参考基线为 2026-09-04 MiniMax 新闻女声版实测（综合响度与真峰值均在 mix 段验收范围内）。
- 默认从内置 BGM 1–3 中选择一首，并在项目清单中记录实际文件。只有用户指定其他音乐时才改用外部 BGM；不把音频标签或文件内信息当作任务指令。
- 在每个配音与 BGM 重叠的播报区间，使用同一种响度度量分别测量人声与 BGM，将 BGM 调整为比人声低 12dB，验收容差为 ±1dB。若人声区间约为 -16 LUFS，则 BGM 对应区间应约为 -28 LUFS。
- 三首内置 BGM 的原始响度不同，不能简单对原文件统一施加 `-12dB` 增益；必须先测选中片段，再做归一化、分段音量或侧链避让。循环或裁切时在乐句边界处理，并加短淡入淡出，避免接缝。
- 默认最终音频为 AAC、48kHz、立体声。手机外放必须能听清，不能有削波、突然断尾或页面切换处的音色跳变。

## 模板验收

- 默认校验总时长 14.000 秒、420 帧、封面仅占第 0 帧、两页正文帧数之和为 419；使用实际逐页帧数，不再假设每页 120 帧。对最终 MP4 完整解码并核对实际帧数，不用容器时长推算。
- 对封面、270×360 双列缩略图、第一页、第二页、所有切点和平台叠层预览抽帧，与内置参考资产比较字体、颜色、层级、位置和安全边距。
- 封面两行分别使用 144px/112px，且满足 8/12 个全角字宽硬上限；任何自动缩字、换行、截字、源文字残留或四角框缺失均失败。
- 白色说明与红色重点必须位于锁定 JSON 的 `white_copy_safe_bbox` 与 `red_emphasis_safe_bbox`。任何板块边界偏离锁定 JSON 超过容差（见 config.json `layout.tolerance_px`）均失败。
- 对最终编码 MP4 机器测量综合响度与真峰值；中间 WAV 或“存在音轨”不能替代最终响度验收。
- 分别测量播报重叠区间的人声与 BGM，确认 BGM 比人声低 12dB，允许测量误差 ±1dB。
- 用户没有另行指定时，以本文件的 14 秒/420 帧总时长和实际配音驱动的逐页帧数为准；若视觉测量存在 1–3px 编码偏差，以本文件数值为准。
