# 支付宝内容创作平台发布管线（手机通讯生活）

> 版本：1.3（2026-09-15 三次修订：单视频流程规范化）
> 适用环境：Windows 11、用户日常 Chrome、`computer-use` 桌面自动化
> 适用流程：用户验收成片 → 明确发布指令 → Chrome 冷启动 → 登录与账号校验 → 平台上传 → 封面/声明 → 批量或单条发布 → 发布后核验
> 1.0 依据 2026-09-14 双视频实跑整理；1.1 依据 2026-09-15 用户反馈与页面截图修订四项：Chrome 冷启动、固定坐标快速连击、登录后生活号校验切换、封面推荐帧优先与队列点击切换。

## 1. 触发条件与授权边界

本管线只在用户对已交付成片发出**明确发布指令**后启动，例如"内容没问题，请帮我发布""发布到手机通讯生活""把今天几条发出去"。含糊表态（"看起来不错"）不构成发布授权。

- 发布对象是 config `output` 段定义的输出区中、用户已验收的最终 MP4（文件名 = `cover_title_full`，见 config `output.cover_title_full_pattern`）及其所在主题目录。
- 发布是**不可逆对外行为**：只发布用户点名的条目；用户点名"今天这批"时，发布该日期目录下全部通过验收的主题，发布前列出清单让用户可打断。
- 未获明确指令不得上传；登录只依赖用户浏览器内置的密码管理器自动填充，Agent 不索取、不键入、不回传账号密码与验证码。

## 2. 环境选择与 Chrome 冷启动（硬性约束）

必须用 `computer-use` 驱动**用户日常 Chrome（真实配置文件）**，禁止 agent-browser 或其他独立自动化浏览器实例。理由：

1. 支付宝登录凭据只存在于用户 Chrome 的密码管理器；干净实例没有凭据，也没有短信验证码通道，登录会直接卡死。
2. 蚂蚁系站点风控对自动化浏览器特征（CDP、`navigator.webdriver`、全新指纹）敏感；用真实环境发布行为最不容易触发滑块、短信校验或账号限流。
3. 上传流程包含 Windows 原生文件对话框，属于"网页 + 系统对话框"混合流程，computer-use 可全程覆盖。

**Chrome 冷启动流程**（Chrome 未运行时，`open_application` 按名称经常找不到它，必须走完整路径）：

1. 先 `list_apps` 查找 Chrome（名称可能显示为 Chrome / Google Chrome）。
2. **已在运行**：`open_application` 附着即可，必要时激活并把窗口最大化（最大化即第 3 节的窗口锁定），跳到第 4 节。
3. **未运行**：用完整路径 + 发布页 URL 冷启动（PowerShell 7；路径见 config `platform_publish.browser_launch.chrome_path`，URL 见 `platform_publish.publish_url`）：

   ```powershell
   pwsh -NoProfile -Command "Start-Process 'C:\Program Files\Google\Chrome\Application\chrome.exe' -ArgumentList '--start-maximized','--new-window','https://c.alipay.com/page/content-creation/publish/short-video?appId=2016011301909316'"
   ```

   - 必须使用默认真实配置文件：**禁止** `--user-data-dir`、`--incognito` 等参数，否则会启动无密码管理器、无登录态的干净实例，登录直接卡死。
   - `--start-maximized` 让新窗口以最大化打开，为第 3 节固定坐标提供确定的窗口状态；Chrome 已运行时新标签会忽略该参数，所以已运行分支要在窗口层面确认最大化。
4. 启动后 `wait` 2–3 秒，再 `list_apps` / `get_app_state` 确认 Chrome 进程出现、发布页开始加载；页面标题含「支付宝内容创作平台」即入口正确，再进入第 4 节。

## 3. 固定窗口与快速连击（执行速度策略）

发布页控件在窗口状态不变时位置固定；逐次"截图 → 识别 → 点击"是整条管线最大的耗时点。本节定义何时可以连击、何时必须停下来校验：

1. **窗口锁定**：进入发布页后先固定窗口状态（最大化或保持当前尺寸不变），整个运行期间不得拖动、缩放、最小化 Chrome 或更改显示器分辨率；此后标定的坐标才可复用。
2. **基准标定**：拍一张全屏基准截图（或读一次无障碍树），从其上确定本批发布要用的全部固定坐标：左队列各槽位缩略图、「+ 添加视频」、封面图片推荐各缩略图、「上传封面」入口、右上「批量编辑」「批量发布」、确认弹窗内「确定 / 开始发布」等。
3. **连击执行**：对上述稳定控件按固定坐标**连续点击**，两次点击之间只加 0.3–1 秒 `wait`，不重新截图、不重读无障碍树。典型连击串：逐条"点左队列槽位 → 点匹配的推荐缩略图"一口气完成全部条目的封面设置。
4. **必查校验点（只有这些步骤重新观察）**：
   - 登录后账号校验（第 4 节）；
   - 每条视频的就绪门（第 6 节——缩略图进度 100% 消失、预览可播，**不可跳过、不可用连击代替**）；
   - 每条封面应用后，封面预览大图已更新为所选画面（可与就绪门合并为一次检查）；
   - 批量发布后进度环 N/N 全部变绿、出现"发布完成"；
   - 内容管理已发布列表逐条核对（第 10 节）。
5. **兜底**：任何校验点失败、出现意外弹窗、或点击后没有预期反应 → 立即停止连击，回到"观察 → 点击"单步模式，重新标定坐标、排除异常后再恢复连击。窗口状态一旦改变（拖动、缩放、切换显示器、Chrome 重启），旧坐标全部作废，必须重新标定。

## 4. 入口、登录与账号校验

1. 直接打开发布页 URL（config `platform_publish.publish_url`，含 appId）。会话有效时直接落在「短视频创作」页；标题栏出现「支付宝内容创作平台」即认为入口正确。
2. 会话过期会 302 到 `auth.alipay.com` 登录页，默认显示二维码。切换到「账户登录」标签（该页标签为 账户登录/扫码登录/验证码登录，"密码登录"并非标签名），点击账号输入框后 Chrome 密码管理器自动填充账号与密码，点「登录」。
3. **登录后账号校验（硬门）**：登录成功后平台停留在"上次使用的应用"，**不保证是目标生活号**——即使 URL 带 appId，也可能落在「双V会员」「冲鸭攒话费」等其他生活号。以**页面左上角（左侧导航顶部账号卡）显示的账号名**为唯一判据：
   - 账号名 = config `platform_publish.account`（手机通讯生活）→ 校验通过，进入第 5 节。
   - 显示其他生活号（该账号下已知还有：双V会员、冲鸭攒话费、名称释放）→ 执行生活号切换：
     1. 若「请选择应用」弹窗已自动弹出，直接进入下一步；
     2. 否则点击左上角账号卡（账号名旁有「切」切换标记）打开「请选择应用」弹窗；
     3. 弹窗内按**名称**选中目标生活号行（行内含应用 ID，可与 config `platform_publish.app_id` 交叉核对），点右下「确定」，等待页面以目标生活号重新加载；
     4. **复核**左上角账号名已变为目标生活号，才能进入上传。复核不通过时重走本节切换流程，不以 URL 或弹窗关闭为准。
4. 登录态过期是常态而非异常；每次发布运行都预期可能重新登录一次，且每次登录后都要重做账号校验。

## 5. 上传视频

1. 在短视频创作页点击「点击上传」（或「拖或上传」区域）。
2. 原生文件对话框打开。**对话框属于独立的 Chrome 子进程（pid 不同于主窗口）**，点击其控件前先激活该 pid。
3. 视频路径含中文，不要逐字键入：把完整路径写入剪贴板 → 点击「文件名」输入框 → `Ctrl+V` → `Enter`。直接回车会打开文件；有时点「打开(O)」按钮只会进入目录，回车更可靠。
4. 也可先在对话框中手动导航到 config `output.root` 下的日期目录再双击文件，两种方式等价；完整路径粘贴更快。

## 6. 就绪门（最关键的一步）

**每条视频必须等左侧缩略图上的上传进度标记消失（100%）、右侧手机预览可播放后，才能进行后续步骤或批量发布。**

实跑证据：2026-09-14 双视频批量发布中，一条未完全就绪的条目被平台**静默丢弃**——无任何报错弹窗，不在「已发布/审核中/审核未通过/封面待优化/草稿箱」任何标签中出现，创作页草稿队列也清空，只能整体重传。发布脚本没有兜底，就绪门是唯一防线。

就绪的辅助判据：封面推荐帧（封面图片推荐）已生成、右侧预览能加载出视频画面、缩略图显示为视频画面而非进度环。就绪门属于第 3 节的必查校验点，即使整体走连击模式，这里也必须实际观察确认。

## 7. 标题与封面（推荐帧优先）

- **标题描述**：平台自动用文件名填充，即 `cover_title_full`（主标题+全角逗号+副标题），直接保留，除非用户明确给出别的标题。确认字数计数未超限。
- **条目切换不用滚轮**：为第 2…N 条设置封面或字段时，直接点击左中部视频队列中该条的**缩略图槽位**，把编辑面板切换到该条（位置固定，适合连击）；不要用滚轮在长表单里来回滚动找字段。
- **封面设置（新流程）**：
  1. 该条通过就绪门后，「封面」区出现封面预览大图和「封面图片推荐」缩略图行。
  2. **优先**：点击「封面图片推荐」中与封面预览大图画面**一致**的那张缩略图（即视频首帧标题卡对应的推荐帧）。此路径替代 1.0 的「点占位框 → 截取封面 → 完成」弹窗流程。
  3. **缩略图高亮 ≠ 封面已设置（2026-09-15 实跑教训）**：点击后缩略图出现蓝色高亮、预览更新，但封面字段可能仍未登记，点「确认发布」会被「请选择视频封面」拦截。补救：回到封面区**重新点击一次**该推荐缩略图，再点「确认发布」，实测即通过；仍被拦截才走第 4 步兜底。判据以「确认发布不再报错」为准，不以高亮为准。
  4. **兜底**：点击封面区推荐行内带"上传封面"字样的**第一格**（注意：表单下方「消息封面设置」区也有一个「上传封面」按钮，**那是另一个字段，不要点错**；点错会弹出「消息封面」对话框，直接点「取 消」退出即可）→ 打开原生文件对话框 → 按第 5 节对话框流程粘贴该主题目录 `封面.png`（config `output.cover_name`）的完整路径 → `Enter` → 确认应用。上传的必须是输出区该主题目录中已验收的独立封面文件。
  5. **校验点**：封面预览大图已变为所选画面，且「确认发布」不再被「请选择视频封面」拦截，该条封面才算完成。
- 弹出浏览器位置权限等无关弹窗时点「一律不允许」/关闭，不阻塞主流程。

## 8. 多视频批量流程

1. 第一条就绪后点左侧「+ 添加视频」加入下一条；每条重复第 5–6 节（上传 + 就绪门）。
2. 全部就绪后，按第 7 节用左队列点击逐条设置封面：连击串「队列槽位 → 匹配的推荐缩略图」，无匹配的条目才走「上传封面」兜底；每条应用后确认预览已更新。
3. **作者声明**：点右上「批量编辑」（批量操作）→ 作者声明选第一项（批量弹窗中「内容无需标注」为第一项）→ 「确定」，统一应用到全部条目。注意单页布局的选项顺序与批量弹窗**不同**，「内容无需标注」在单页是最后一项（见第 9 节），两处都必须按名称选择。
4. **发布前检查门**：逐条确认左侧每个缩略图都没有进度标记。任何一条未就绪就点发布，该条会被静默丢弃（见第 6 节）。
5. 点「批量发布」→ 弹窗确认全部条目勾选 → 「开始发布」→ 等待进度环 N/N 全部变绿、出现"发布完成"（第 3 节校验点），页面随后自动跳转「内容管理」。

## 9. 单视频流程（与批量的关键差异）

队列中只有一条时，页面**不出现「批量发布」「批量编辑」按钮**：设置项全部在单页表单内完成，发布按钮为页面底部「确认发布」，**无批量确认弹窗、无进度环 N/N 环节**，成功后直接自动跳转「内容管理 → 已发布」。以下为 2026-09-15 实跑验证的完整点击序列。

### 9.1 进入干净会话

1. 浏览器已有遗留草稿标签页（拆分视图、旧「商家平台」会话）时**不要复用**：`Ctrl+T` 新开标签页，地址栏输入 config `publish_url` 回车。干净会话的页面标题为「支付宝内容创作平台」，呈空白上传页（居中大按钮「点击上传」）；旧草稿页标题多为「商家平台」，以此区分。
2. 账号校验（第 4 节）：左上角账号卡名称 = 目标生活号；侧边栏「内容安全/直播安全」等链接的 appId 应为目标应用 ID。
3. 旧草稿标签页原样保留：不保存、不发布不属于本次授权的内容，发布完成后向用户报告其存在。

### 9.2 上传与就绪

1. 点「点击上传」→ 原生文件对话框（独立 pid，先激活）→「文件名」框粘贴完整路径 → `Enter`。
2. 单条就绪判据比批量直观：表单自动填充标题（= 文件名，即 `cover_title_full`）、创作助手出现「作品未见异常」、左侧缩略图为视频画面且无进度环、「封面图片推荐」已生成缩略图。

### 9.3 表单设置（全部在页内完成，自上而下）

- **标题描述**：自动填充为 `cover_title_full`，保留；确认字数未超限。
- **保持默认、不点击的字段**：作品描述、话题与地点、征稿活动、加入合集、关联推荐（默认不关联）、直播预告、AI智能优化、评论设置（默认展示全部）。
- **消息封面设置**：**绝不点击**其「上传封面」按钮（假入口，属另一字段，见第 11 节）。
- **封面**：按第 7 节执行（推荐帧优先 + 高亮≠已设置的二次点击规则 + 上传兜底）。
- **作者声明（必填，与批量不同的关键点）**：单页布局的选项顺序为 内容为转载 → 内容含营销信息 → 内容虚构演绎，仅供娱乐 → 内容由AI生成 → 个人观点，仅供参考 → **内容无需标注（最后一项）**。必须**按名称**点选「内容无需标注」；不要沿用"选第一项"的批量弹窗惯性——单页第一项是「内容为转载」，点错会把作品标为转载。
- **可见范围**：点「公开：所有人可见」确认（默认已选，幂等点击无害）。
- **发布时间**：点「立即发布」确认（默认已选）。

**AX 操作要点**：单选框不暴露选中态，点击后以重新观察时该 radio 呈 `focused` 作为落点信号；每个选项点击常引起页面滚动、使无障碍状态过期（报 state superseded），**重新 get_app_state 后再点下一项**即可（实测每个选项约一次重读）。三项设置完成后、点「确认发布」前，截图做一次视觉复核：三个单选均为实心选中态（立即发布 / 公开 / 内容无需标注），左侧队列仅一条且无进度标记。

### 9.4 发布与拦截处理

1. 点底部「确认发布」（「保 存」在其左侧，不要点错）。
2. **无确认弹窗**，平台直接校验：若被「请选择视频封面」拦截 → 按第 7 节第 3 条重新点击该推荐缩略图 → 再点「确认发布」。
3. 成功后页面**直接自动跳转**「内容管理 → 已发布」。

### 9.5 发布后核验

1. 跳转后列表可能短暂显示「暂无作品」，等 3–5 秒加载完成再读（第 11 节）。
2. 以「已发布」列表第一条 = 标题 + 当天时间戳判定成功；缺失时的排查与补发路径同第 10 节，补发仍走本节单视频流程。

## 10. 发布后核验（必做）

1. 发布成功后页面自动进入「内容管理 → 已发布」。**以该列表为准判定成败**，不以发布弹窗消失或跳页为准。
2. 逐条按标题 + 当天时间戳核对每一条目标视频；一条都不少才算完成。
3. 某条缺失时依次检查「审核中 → 审核未通过 → 封面待优化 → 草稿箱」。审核中/待优化属平台侧状态，如实报告用户；审核未通过需读出违规原因。
4. 全部标签都没有、且创作页草稿也没有 → 该条发布被静默丢弃 → **重新上传补发**；此时队列只有这一条，走第 9 节单视频「确认发布」流程。
5. 补发同样要过第 6 节就绪门；重传后封面与声明需重新设置（封面仍按第 7 节推荐帧优先）。

## 11. 环境障碍处理手册

- **Chrome 未运行且按名称找不到**：走第 2 节完整路径冷启动，不要反复重试 `open_application` 名称。
- **账号落在错误生活号**（双V会员/冲鸭攒话费等）：走第 4 节切换流程；切换后必须复核左上角账号名。
- **焦点抢占**：用户可能同时在用其他应用（如 Workbuddy）。视觉点击前先 `open_application(activate=true)` 激活 Chrome；整屏截图截到的是前台窗口，被遮挡时改用无障碍树读取状态。
- **帧过期拒绝**：点击报 "frame is stale" 时不要重试旧帧，重新激活 + 重新截图 + 用新帧坐标点击。
- **无障碍按压失效**：网页自绘标签页（如内容管理的状态标签）对 AXPress 语义按压无响应，必须用真实坐标点击；原生按钮（如「点击上传」）AXPress 有效。
- **文件对话框独立进程**：对话框的 pid 与 Chrome 主窗口不同，点击其控件前先按该 pid 激活。
- **键盘输入**：Windows 上键盘事件要求目标窗口前台；粘贴路径前后不要插入会抢焦点的操作。
- **连击失准**：连击过程中任何一步点击无预期反应，立即退回单步模式重新标定（第 3 节第 5 条）。
- **发布被「请选择视频封面」拦截**：说明推荐缩略图点击未登记封面字段，按第 7 节第 3 条重新点击一次该缩略图再发布；仍失败走上传封面兜底。
- **点错「消息封面设置」的上传封面**：弹出「消息封面」对话框时点「取 消」退出，不设置该字段；视频封面入口在封面区推荐行第一格（见第 7 节第 4 条）。
- **内容管理刚跳转显示「暂无作品」**：列表异步加载，等 3–5 秒再读；以加载完成后的列表为准。
- **发布中途被打断**：以「内容管理」列表为唯一事实源重新盘点，缺哪条补哪条，不盲目整批重发。
