# 已确认成片的锁定版式与分区验收

本文件把用户已经确认的 `finished-video-reference.mp4` 拆成可直接查看的关键帧和板块。制作封面、正文页面或最终验收时必须读取；用户没有明确要求改版时，不得凭感觉改变这里的坐标、字号、颜色层级或板块顺序。

确认成片原本使用黑色板块；用户后来明确确认改为深海蓝。因此本模板只用确认成片锁定几何、文字层级、封面结构与分页节奏，板块底色统一替换为 `#071529 → #0B2D55`，不得恢复纯黑。

## 1. 唯一坐标源

机器可读参数以 [layout-lock-v1.json](../assets/references/locked-layout/layout-lock-v1.json) 为唯一坐标源。Markdown 中出现的坐标只用于解释；发生差异时以 JSON 为准，并修正文档，不得让不同实现各自维护一套数字。

## 3. 渲染前分板验收

在渲染完整视频前，先运行：

```powershell
python scripts/extract_layout_proof.py <草稿或最终MP4> --page-frame-counts <第一页帧数,第二页帧数> --out-dir <工作区/qa/layout-proof>
```

该脚本从目标视频抽取封面、各页稳定帧、每个分页切点、末帧，并把每页拆成 `header`、`footage`、`body` 三个独立文件。脚本只证明尺寸、帧数和证据文件完整；以下视觉项必须实际逐张打开检查，不能看到脚本退出码为 0 就填写通过：

### A. 封面板

- 先看 `cover-full.png`，再看 `cover-3x4.png` 和 `cover-thumbnail-270x360.png`。
- 真实下载画面必须覆盖 1080×1440 内容区，主体或场景在 270×360 中仍可辨。
- 只允许 V3 透明四角框；不得出现纯黑空底、不透明暗层、主播、源文字、“资料画面”或素材账号说明。
- 主标题 144px、副标题 112px，位置必须与参考框一致；文案过长时改写，不移动框、不缩字号。

### B. 顶部标题板

- 打开每个 `page-XX-header.png`，与 `reference-header.png` 并排查看。
- 高度必须为 464px；主标题可见区域、副标题黄条和 `y=454–456` 分隔线不得上下漂移。
- 板底必须是深海蓝渐变，不是参考视频中的纯黑，也不能因主题更换而改色。

### C. 中段实拍板

- 打开每个 `page-XX-footage.png`，尺寸必须为 1080×1054。
- 四边全部由有效素材填满；无黑边、空白、模糊复制补边和遮字黑块。
- 主体焦点不得被 `cover` 裁切切断；原始顶部/中部文字为零，允许的底部字幕局部模糊必须不可读且不遮挡主体。

### D. 底部正文板

- 打开每个 `page-XX-body.png`，与 `reference-body-page1.png`、`reference-body-page2.png` 并排查看。
- 板高固定 402px，深海蓝渐变；角标、页码、白字、红字、来源和底线各在自己的固定框内。
- 每页只能是 1–2 行白色说明加 1 行红色重点。红字必须是独立文本层，不得用同色整段、自动挑词或只描红几个字替代。
- 白字不得进入平台账号与标题遮挡区。红字允许和左侧蓝色账号 Logo 轻微重叠，但被遮挡面积不得超过 25%，完整语义仍可读。

### E. 切点与末帧

- `cut-XX-before.png` 与 `cut-XX-after.png` 必须直接切换，不得出现叠化、重影、模糊帧或黑帧。
- `final-frame.png` 必须保持完整正文与声音尾部，不得提前清空文字或画面。

## 4. 强制失败条件

任一分板缺失、尺寸不符、未实际查看，或出现下列情况，状态固定为 `BLOCKED_VISUAL`：

- 封面没有可识别真实画面或出现纯黑空底；
- 标题区、实拍区、正文区边界与 JSON 不一致超过 2px；
- 实拍区小于 1080×1054，或通过黑边/模糊背景补满；
- 正文没有独立红色重点行；
- 白字、红字、角标、页码或来源跨入其他板块；
- 只查看完整帧，没有查看脚本拆出的板块；
- 使用参考图的示例新闻文字代替当前新闻文案。

完成分板验收后才能渲染或发布完整成片；最终编码 MP4 必须再次运行同一脚本，不能只验收渲染前预览。
