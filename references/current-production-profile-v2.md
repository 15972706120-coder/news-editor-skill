# 当前制作配置 V2（最高优先级）

本文件记录用户最新确认的增量要求。它优先于 Skill 内仍保留的 V1 历史坐标、Edge TTS、带声音变体后缀的命名示例，以及“封面可局部模糊”的旧规则。出现冲突时执行本文件；V1 只用于回看历史成片。

## 1. 声音

- 默认 `audio_mode=minimax_tts_bgm`：MiniMax 配音 + BGM；下载素材原声全部静音。只有用户明确要求时才保留环境声。
- 使用 [MiniMax TTS 集成](minimax-tts.md) 和 `scripts/minimax_tts.py`，默认 `speech-2.8-hd` 与非新闻主播音色 `Chinese (Mandarin)_Reliable_Executive`。不得继续使用 Edge TTS，也不得默认选择 `Chinese (Mandarin)_News_Anchor`。
- Skill 完善、文案、视觉、下载和离线测试均不需要 API Key。第一次真正生成配音前才检查 `MINIMAX_API_KEY` 与账号站点；缺失时停在 N8，请用户在本机配置，不让用户在聊天中发送密钥。
- MiniMax 仍属于机器合成音；成片不得宣称接入 MiniMax 即自动满足平台审核。每个项目的 `qa-report.json` 记录 `platform_voice_policy_review=manual_required`。

## 2. 正文 V2 坐标

唯一坐标源为 `assets/references/locked-layout/layout-lock-v2.json`：

```text
画布：1080×1920
标题区：[0, 0, 1080, 344]
副标题黄条：[26, 248, 1028, 80]
黄线：[0, 340, 1080, 4]
实拍区：[0, 344, 1080, 1024]
正文底板：[0, 1368, 1080, 552]
角标/页码 y=1408
白字：[54, 1498, 766, 116]
红字：[54, 1648, 766, 58]
来源：[800, 1838, 226, 30]
```

这些坐标把用户参考图归一化到 1080×1920 后，将文字组下移约 200px，并用腾出的上部空间放大中段素材。不得在 V1 坐标上机械再加 200px，否则红字和来源会越出画布。V2 必须通过实际平台叠层预览；自动坐标匹配不代表平台遮挡合格。

## 3. 封面干净帧硬门

- 封面底图必须是清晰、对焦准确、主体可辨的真实下载帧，且在叠加自有标题前已经无任何可辨字幕、标题、日期、账号贴纸和说明文字。
- 封面底图的 `blur_regions=[]`、`mosaic_regions=[]`。禁止模糊、马赛克、像素化、修补块、生成式填充或遮字色块；只能换干净时间点、裁切、等比缩放、移动焦点及轻度曝光/色彩调整。
- 找不到干净帧时返回 N4 换时段或素材；仍无合格候选则 `BLOCKED_VISUAL`，不能降级使用模糊封面。
- 必须保存并实际查看 `cover-source-original`、`cover-base-before-title`、完整封面、270×480 和 270×360 缩略图。OCR 只用于提示可能文字；OCR 没识别出文字不能自动证明“无字幕”。

## 4. 正文清晰度

- 下载时选择平台可获得的最高质量可解码版本并记录格式、源分辨率和码率；禁止先下载低清版再靠锐化或 AI 放大掩盖。
- 对每个实际使用片段按 V2 实拍区生成最终目标裁切的首/中/尾帧。优先源素材短边至少 720px；目标裁切放大倍率 `<=1.5` 为首选，`>1.5` 需换片比较，`>2.0` 为硬失败。
- 禁止拉伸、`contain` 黑边、全幅模糊补边、全幅马赛克和无意义锐化。正文仅允许对不可裁除的底部字幕做紧贴文字的局部高斯模糊；封面不适用此例外。
- 尽量保持单次重采样和单次最终有损编码。推荐 H.264 CRF 18–20、`yuv420p`；发布前 100% 查看目标裁切帧和全片，检查失焦、运动模糊、压缩块、色带、重复编码损伤和动态字幕回流。
- 分辨率、码率、锐度、块效应、OCR、SSIM/VMAF 都只能作为机器告警或候选排序，不能单独证明画面清晰。

## 5. 命名

- 在文案阶段锁定唯一字段 `cover_title_canonical`，即封面主标题的实际文字（不包含副标题）。
- 发布目录为 `N.<cover_title_canonical>`；最终文件为 `<cover_title_canonical>.mp4` 和 `封面.png`。禁止附加 `-新闻女声`、`-MiniMax配音`、`-BGM版`、时长、版本号、`FINAL` 或 `draft`。
- Windows 不允许的文件名字符必须在封面文案定稿前改为意思一致的可用文案；不得发布时静默替换，避免画面标题和文件名不一致。
- 发布检查必须验证 MP4 basename 与主题目录去掉 `N.` 后完全一致；封面图片中的主标题仍需人工核对，不能用脚本文件名替代视觉确认。

## 6. QA 证据边界

`FINAL_READY` 同时要求：

- `machine_hard_gate`：尺寸、帧率、帧数、音频规格、最终响度、真峰值、逐页配音时长、放大倍率、命名一致性。
- `machine_warning`：OCR 候选、锐度、块效应、码率、黑区比例、冻结帧；只产生复核提示。
- `mandatory_human_review`：封面原始帧/干净底图/缩略图无字幕无码，正文全片清晰度，动态文字、素材身份、平台遮挡，逐页 TTS 发音及手机外放混音。

每项记录 `assertion_source`、证据文件、帧号或试听区间、检查时间；不得把机器代理指标写成视觉或听觉事实。
